milktea, anywhere on the page

Each example is an inline element. They load when you scroll them into view and pause offscreen. Click to use the keyboard; the corner button enters real fullscreen and keeps the same running example.

A full animation in a small box

A fixed 80 × 24 grid fits into the box. Fullscreen enlarges the same grid without restarting the cycle.

Drawing at a different scale

Mouse positions stay accurate as the canvas scales. Focus before using the scroll wheel.

Try your own viewport

With a fixed grid, the whole example scales to fit. Turn that off to let font size and zoom determine how many cells fit in the viewport.

<script type="module" src="/milktea/embed.mjs"></script>
<milktea-view src="/milktea/build/nanobots.wasm"
  cols="80" rows="24" style="width:400px;height:240px">
</milktea-view>

This example waits for you

Doom fire’s WASM is requested only when this embed enters the viewport. Another instance of the same example reuses the compiled module and runs with its own state.

Change CSS width and height freely. Set loading="eager" to start loading immediately, or expandable="false" to hide the fullscreen button.
