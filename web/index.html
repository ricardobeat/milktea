Model, update
and view

The runtime delivers messages to update and renders the result of view.

  1. Model

    Application state.

  2. Update

    Handles input and timer messages.

  3. View

    Return text, a layout tree, or a cell grid.

Glaze provides styling. Xray provides layout and compositing. These demos run through WebAssembly.

a counter’s update & viewC3
struct Counter { sz count; }

fn milktea::Cmd Counter.update(&self, milktea::Msg msg) @dynamic {
  if (msg.kind == milktea::MsgKind.KEY &&
      msg.key.code == milktea::KeyCode.UP) self.count++;
  return null;
}

fn milktea::Node* Counter.view(&self) @dynamic {
  String label = string::tformat("Count: %d", self.count);
  return milktea::text(label, glaze::style()
    .foreground(glaze::color_hex("#a8d5ba"))
    .with_border(glaze::ROUNDED)
    .padding(1, 2, 1, 2));
}
