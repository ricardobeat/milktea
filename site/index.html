milktea ▮

A terminal UI library for C3. Build TUIs the calm way — as a model, an update, and a view.

lang · C3 style · Elm Architecture deps · zero, beyond C3 vibe · cozy ☕

milktea is a little framework for writing programs that live in your terminal — text editors, dashboards, installers, games, whatever. You describe your app as plain data, write a function that reacts to events, and a function that draws the screen. milktea takes care of the boring parts: the event loop, drawing, and wrangling the terminal.

No callbacks. No tangled state. No surprises. Just a struct and three functions.

counter.c3 
struct Counter { int value; }

// react to events
fn Cmd Counter.update(&self, Msg msg) {
    switch (msg.key.code) {
        case UP:   self.value++;
        case DOWN: self.value--;
        case RUNE: if (msg.key.rune == 'q') return quit();
    }
    return null;
}

// draw the screen
fn View Counter.view(&self) {
    return new_view(string::tformat(
        "Counter: %d  (↑ ↓ to change, q to quit)", self.value));
}

A small family of parts

milktea is the runtime. Around it sit three friends, each with one job. Import only what you need — a tiny app needs just the first two.

runtime

milktea

The event loop and the glue. Keys, mouse, window resizes, timers — it pipes them to your update and redraws after.

init · update · view · tick
styling

glaze

Colors, borders, padding, gradients. Perceptual color blending and animated borders for when you want to show off a little.

xray

The cell grid underneath it all. A diffing renderer that only repaints what changed, plus a layout solver for splitting space.

vstack · hstack · fill · len · percent
components

boba

Ready-made widgets so you don't start from zero: lists, tables, text inputs, spinners, timers, file pickers, toasts, viewports.

list · table · textinput · spinner · timer

What's in the box

  • Truecolor, 256-color, and palette colors — with perceptual blending
  • Rounded, double, thick, and animated borders
  • A constraint-based layout solver (vstack / hstack)
  • Smooth animations via frame-paced ticks and a flicker-free renderer
  • Full mouse support — clicks, motion, the works
  • Alternate-screen full-window apps, or inline one-shot tools
  • Drop-in components: tables, text areas, progress bars, file pickers

See it run

The examples/ folder is full of runnable demos — from a 20-line counter all the way up to a raycasting 3D engine and a fire effect, both running entirely in text cells.

~/milktea/examples/wolf3d
$ cd examples/wolf3d
$ c3c run
  ▲ a wolfenstein-style raycaster, in your terminal ▲

Other favorites: doom-fire, color-swatches, split-editors, dos-app, and a timer.
